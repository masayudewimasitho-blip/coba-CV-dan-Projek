Proyek Akademik Utama

Aplikasi Mobile Tabel Kebenaran & Penyederhanaan K-Map

Aplikasi Android berbasis Java untuk komputasi aljabar logika biner dan visualisasi rangkaian logika digital.

Java Android Studio Logika Digital
Tantangan / Problem

Perhitungan tabel kebenaran dan penyederhanaan aljabar Boolean menggunakan metode Karnaugh Map (K-Map) secara manual membutuhkan ketelitian tinggi serta rentan kesalahan komputasi seiring bertambahnya variabel input.

Solusi / Pendekatan

Mengembangkan aplikasi mobile terprogram yang memvalidasi input logika pengguna secara sistematis, mengotomatisasi generasi tabel kebenaran, dan memetakan struktur representasi rangkaian logika yang sesuai.

Fitur Utama Aplikasi:

  • Input Data Dinamis: Memproses berbagai kombinasi data logika yang dimasukkan oleh pengguna secara fleksibel.
  • Generasi Tabel Kebenaran Otomatis: Menghasilkan pemetaan kondisi logika biner secara instan tanpa kalkulasi manual.
  • Visualisasi Rangkaian Logika: Menampilkan representasi susunan gerbang logika dari hasil ekspresi logika yang diproses.
  • Skalabilitas Bertahap: Mendukung pengolahan sistem logika dari 2 variabel input hingga diperluas menjadi 4 variabel input.
Peran Saya Pengembang Mandiri (Perancangan algoritma, UI/UX, dan implementasi logika sistem)
Proses Pengembangan Dikembangkan secara iteratif: riset algoritma logika 2 variabel, pengujian fungsionalitas, lalu ekspansi modular ke 3 dan 4 variabel.
Hasil & Dampak Aplikasi berfungsi penuh untuk validasi logika akademik. [Metrik kuantitatif belum diisi]
